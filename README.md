# Dtv - High-Performance IPTV Stream Viewer

Dtv is a minimalistic, high-performance IPTV stream viewer designed for clarity, speed, and ease of use. It provides access to thousands of live TV channels from around the world with a refined, eye-friendly interface.

## 🚀 Features

- **Massive Channel Library:** Access to 39,000+ channels via the IPTV-org project.
- **Strict Quality Control:** Optimized for 720p playback to ensure a balance between quality and performance.
- **Smart Filtering:** Browse by category (News, Movies, Music, Sports, etc.) or search for specific channels.
- **Real-time Loading Updates:** Transparent multi-step loading indicator for stream initialization.
- **CORS Proxy Support:** Built-in fallback for streams restricted by cross-origin policies.
- **Minimalist Design:** A clean, distraction-free interface with smooth animations.

## 🛠️ Tech Stack

- **React 19** - UI Framework
- **TypeScript** - Type Safety
- **Vite** - Build Tool
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations
- **HLS.js** - Video Streaming Engine
- **Lucide React** - Iconography
